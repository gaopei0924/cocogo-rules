# Cocogo

対訳リーダー。原文の下に訳文を一行ずつ。洋書一冊を最後まで読み通せます。

ウェブページ、選択テキスト、動画字幕に対応。OpenAI・Claude・Gemini・DeepL などのキーをご自身で設定できます。

---

## このリポジトリについて

Cocogo の**公開アセット**を置いています。拡張機能が実行時に取得します。

| ファイル | 用途 |
| --- | --- |
| `cocogo-rules_v2.json` | サイト対応ルール（安定版） |
| `cocogo-rules-on_v2.json` | サイト対応ルール（翻訳を既定でオン） |
| `cocogo-rules-off_v2.json` | サイト対応ルール（翻訳を既定でオフ） |
| `version.txt` | 更新確認用のバージョン情報 |
| `README*.md` | 拡張機能の「情報」ページに表示される内容 |

---

## サイト対応ルール

サイトごとにレイアウトは大きく異なります。対応ルールは、**本文がどの要素にあるか**、そして**触れてはいけない領域**（ナビゲーション、ボタン、コードブロック）を Cocogo に伝えます。

ルールは購読方式で配信されるため、拡張機能を再インストールせずに更新されます。

### 不具合の報告

訳文の位置がずれる、段落が飛ばされる、メニューまで翻訳される — そうした場合は URL とスクリーンショットを添えて[イシューを作成](https://github.com/gaopei0924/cocogo-rules/issues/new)してください。

### 安全性について

Cocogo はリモートの購読ルールを読み込む際、**実行可能なスクリプト項目**（`injectJs`、`transStartHook`、`transEndHook`）を**必ず除去**してから使用します。

つまり、仮にこのルール配信元が侵害されたとしても、閲覧中のページでコードが実行されることはありません。スクリプトを持てるのは、利用者自身がローカルで入力したルールのみです。
