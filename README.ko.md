# Cocogo

대역 리더. 원문 한 줄, 번역 한 줄. 원서 한 권을 끝까지 읽어낼 수 있습니다.

웹 페이지, 선택한 텍스트, 동영상 자막을 지원합니다. OpenAI · Claude · Gemini · DeepL 등의 키를 직접 설정할 수 있습니다.

---

## 이 저장소는 무엇인가요

Cocogo의 **공개 자산**을 보관합니다. 확장 프로그램이 실행 중에 가져다 씁니다.

| 파일 | 용도 |
| --- | --- |
| `cocogo-rules_v2.json` | 사이트 적응 규칙 (안정판) |
| `cocogo-rules-on_v2.json` | 사이트 적응 규칙 (번역 기본 켜짐) |
| `cocogo-rules-off_v2.json` | 사이트 적응 규칙 (번역 기본 꺼짐) |
| `version.txt` | 업데이트 확인용 버전 정보 |
| `README*.md` | 확장 프로그램 '정보' 페이지에 표시되는 내용 |

## 사이트 적응 규칙

사이트마다 구조가 크게 다릅니다. 적응 규칙은 **본문이 어느 요소에 있는지**, 그리고 **건드리면 안 되는 영역**(내비게이션, 버튼, 코드 블록)이 어디인지를 Cocogo에 알려줍니다.

규칙은 구독 방식으로 배포되므로 확장 프로그램을 다시 설치하지 않아도 갱신됩니다.

### 문제 신고

번역이 엉뚱한 곳에 붙거나, 문단이 누락되거나, 메뉴까지 번역되나요? URL과 스크린샷을 첨부해 [이슈를 등록](https://github.com/gaopei0924/cocogo-rules/issues/new)해 주세요.

### 안전에 관하여

Cocogo는 원격 구독 규칙을 불러올 때 실행 가능한 스크립트 항목(`injectJs`, `transStartHook`, `transEndHook`)을 **항상 제거한 뒤** 사용합니다.

따라서 이 규칙 배포처가 침해되더라도 사용자가 방문하는 페이지에서 코드가 실행될 수 없습니다. 스크립트를 담을 수 있는 것은 사용자가 직접 로컬에서 입력한 규칙뿐입니다.
